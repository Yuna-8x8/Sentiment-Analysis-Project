# Sentiment Analysis (IMDB)

## Description
This project implements a sentiment analysis model using a Bidirectional LSTM with pre-trained GloVe embeddings to classify movie reviews as positive or negative.

## Approach
- Text preprocessing using TensorFlow
- GloVe embeddings (100d)
- BiLSTM model

## Results
- Achieved ~86% validation accuracy

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the notebook

## GloVe Setup
Download from:
https://nlp.stanford.edu/projects/glove/

Use: glove.6B.100d.txt
