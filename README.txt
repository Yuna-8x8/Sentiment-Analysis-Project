# Sentiment Analysis (IMDB)

This project implements a sentiment analysis model using the IMDB dataset.

## Approach
- Text preprocessing using TensorFlow TextVectorization
- Pre-trained GloVe embeddings
- BiLSTM model for classification

## Results
- Achieved ~86% accuracy on test data

## Tech Stack
- Python
- TensorFlow / Keras
- NumPy

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the notebook:
   jupyter notebook
